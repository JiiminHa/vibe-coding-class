# Product Brief

## 1. Product Summary
이 서비스는 **카드뉴스를 정기적으로 제작하는 운영진/개인**이 **매번 반복되는 카피 작성과 Figma 편집 작업**을 **키워드 입력 → Claude 자동 생성 → Figma 템플릿 자동 삽입**으로 해결하도록 돕는다.

## 2. Problem
카드뉴스를 만들 때마다 Figma 템플릿을 열고, 텍스트를 하나씩 수정하고, 톤에 맞는 카피를 직접 쓰는 과정이 반복된다. 행사명·날짜·주차 같은 단순 정보도 매번 손으로 채워야 한다. 결과물의 퀄리티가 그날의 컨디션이나 시간 여유에 따라 달라진다. 특히 멋사 운영진처럼 주기적으로 홍보물을 만들어야 하는 경우, 반복 작업에 드는 시간이 누적되면 부담이 된다.

## 3. Target User
- **주요 사용자:** 지민 본인 (멋사 기획·디자인 운영진 + 개인 공부 인스타 운영)
- **사용 상황:** 주 1회 이상 카드뉴스 제작 / 매일 공부 기록 인스타 업로드 전
- **사용자의 기술 수준:** 개발·디자인 툴 능숙, Figma 사용 경험 있음
- **사용자가 기대하는 결과:** 키워드만 입력하면 카피가 완성되고 Figma 템플릿에 자동으로 채워져 있는 상태

## 4. Core Value
키워드만 입력하면 Claude가 카피를 쓰고 Figma 템플릿에 바로 삽입해줘서, 카드뉴스 제작 시간을 10분 이하로 줄인다.

## 5. MVP Scope
- 멋사 홍보 / 공부 기록 두 가지 모드
- 주제·키워드·조건(슬라이드 수, 톤, 타겟) 입력 폼
- Claude API로 카피 자동 생성
- Figma MCP로 등록된 템플릿에 텍스트 자동 삽입
- 처음 한 번만 레이어 역할 매핑, 이후 저장·재사용
- 사진 업로드 → Figma 이미지 슬롯 삽입

## 6. Non-goals
이번 MVP에서 제외할 것:
- 로그인
- 결제
- 실시간 협업
- 대용량 파일 업로드
- 다중 외부 API 연동
- 복잡한 관리자 권한
- 다중 사용자 지원 (본인 전용 툴)
- PNG 내보내기 / 다운로드
- 템플릿 여러 개 동시 관리

## 7. Success Criteria
- 사용자는 핵심 기능(입력 → 생성 → Figma 삽입)을 1분 안에 사용할 수 있다.
- 3회차 종료 시 브라우저에서 기본 흐름을 확인할 수 있다.
- 4회차에서 핵심 흐름을 Playwright 테스트로 검증할 수 있다.
- 최종 결과물은 배포 가능한 형태여야 한다.
